## Docker и сквозной сценарий

В отдельном Compose-проекте `ewa-stage10-check` собраны образы `app` и `ui`.
Проверка выполнялась на macOS ARM64 с Docker Desktop. Базовые Python, uv и
PostgreSQL закреплены по digest. Изображения и стек не публиковались.

`docker compose up -d --wait` дождался готовности API, PostgreSQL, получателя
и Streamlit. Миграционный контейнер завершился успешно. API и страница
публиковались только на loopback.

Пароль PostgreSQL намеренно содержал зарезервированные символы и пробел.
Стек подключился успешно: Compose передаёт сырые `DATABASE_*`, а SQLAlchemy
создаёт экранированный URL. Пароль в журналы проверки не выводился.

`python -m app.smoke --api http://api:8003 --wait 60` успешно выполнил 8 шагов:
`health`, `sign-in`, `upload`, `start`, `check`, `reconcile`, `approve`,
`delivery`. Конечное состояние — `approved`, событие — `delivered`.

Новая ручная проверка страницы в браузере на этапе 10 не проводилась:
готовность страницы проверена по HTTP, её сценарии — тестами Streamlit.
Ручная браузерная проверка этапов 08–09 сохранена в истории разработки.

## Резервная копия и восстановление

В Compose создан вымышленный процесс с документом, сверкой и доставленным
решением. После остановки пишущих приложений выполнен экспорт **23 таблиц,
45 строк**. Затем удалён только `pgdata` этого тестового проекта;
том SQLite получателя сохранён. Новая пустая PostgreSQL-база получила
миграции, после чего выполнены `restore`, `verify` и `check`.

Результат:

- `matches_manifest: true` и `matches: true` для всех таблиц;
- `check`: один процесс, один документ, одна сверка, без ошибок целостности;
- у получателя одно действие до и после цикла, его журнал полностью совпал;
- повреждённые данные, конкурентный писатель и ошибки загрузки проверены
  отдельными тестами отказа и отката.

Копия охватывает только PostgreSQL. Она не экспортирует SQLite получателя
и не даёт атомарного снимка двух хранилищ. CI теперь сохраняет том получателя
при тестировании восстановления; финальная очистка удаляет только временные
ресурсы своего уникального проекта.
