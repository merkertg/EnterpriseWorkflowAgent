повторены. В репозитории таких копий нет. Это свойство машины, а не
проекта.

### Исправлено по ходу этапа

- `AppTest.from_file` не находил страницу по относительному пути — путь
  теперь абсолютный.
- Тест двойного клика сначала ждал повтора из старой вкладки. Но Streamlit
  перезапускает страницу на каждый клик со свежими данными, и старая
  вкладка отправляет уже версию 3. Тест теперь проверяет честный исход —
  `409 invalid_transition` и одно событие outbox, — а повтор с сохранённым
  результатом проверяется на форме запуска.
- Тест команды подготовки пропускался без Streamlit вместе с модулем
  страницы; он вынесен в отдельный модуль и не зависит от группы `ui`.
- Встроенный запуск серверов в панели браузера зависал в состоянии
  «starting», поэтому API и страница для проверки запускались из оболочки.
- Первая сборка PDF дала 37 русских и 36 английских страниц: раздел
  HTTP API и страница итогов не помещались. Описания маршрутов на русском
  сокращены, шесть строк демонстраций объединены в одну.
