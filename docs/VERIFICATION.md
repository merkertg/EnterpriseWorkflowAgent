- Хеш объяснения сначала считался функцией канонического JSON, которая
  принимает только словарь; strict mypy это поймал. Теперь текст хешируется
  через `hashlib`.
- Сборка PDF остановилась на проверке «каждый маршрут описан»: два новых
  маршрута агента не были описаны в разделе HTTP API. Описания добавлены.
- Оглавление на обложке с 31 разделом налезало на нижнюю строку обложки.
  Шаг строк теперь подбирается по числу разделов.
- В тесте извлечения моделью цитаты брались из одного текста, а сохранялся
  изменённый. Тест исправлен; код был верным.
- В демонстрации счёт B сначала не проходил базовую проверку, поэтому
  завышенный черновик отклонялся по состоянию процесса. Цены B теперь ниже
  заказа: базовая проверка проходит, сверка — нет, и срабатывает именно
