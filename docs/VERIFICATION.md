### Исправлено по ходу этапа

- Специалист, указавший чужое подразделение при запуске, сначала получал
  «не найдено» с сообщением о процессе. Подразделение называет сам
  вызывающий, поэтому теперь это `missing_permission`.
- Тест истории для `outbox_events` не находил ошибку: `UPDATE` пустой
  таблицы не вызывает строковый триггер. Тест теперь сначала создаёт решение.
- Проверка «тело ошибки не повторяет присланное» искала имя поля, которое
  законно присутствует в месте ошибки; теперь ищется само значение.
- `git diff --check` принял новую русскую версию PDF за текст: в её первых
  8000 байтах нет нулевого байта, по которому git узнаёт двоичный файл.
  Добавлен `.gitattributes` с `*.pdf binary`; после этого проверка прошла.
- Русская версия PDF занимала 30 страниц: последний блок итогов уходил на
  отдельную страницу. Длинная строка проверки сокращена, и обе версии
  уместились в 29 страниц.
