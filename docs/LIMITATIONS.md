# Ограничения Enterprise Workflow Agent 0.10.0

[README](../README.md) · [Дорожная карта](ROADMAP.md) ·
[Проверка](VERIFICATION.md) · [Этап 10](STAGE_10.md)

Это учебный проект на вымышленных данных. Пройденные проверки, оценки и
smoke-тест **не означают готовности к промышленной эксплуатации**. Ниже —
сводный список того, чего проект не делает или что не проверено. Подробности
— в руководствах этапов и в [VERIFICATION.md](VERIFICATION.md).

## Три вида свидетельств

| Вид | Статус на 24 октября 2026 года |
| --- | --- |
| Локальные проверки | Выполнены на macOS (arm64), PostgreSQL 18.3, Docker Desktop; записаны в VERIFICATION.md |
| Настоящий провайдер модели | Не проверялся: адаптера нет, ключа нет, сетевых вызовов модели нет |
| Удалённый CI (GitHub Actions) | Не подтверждён: результаты запусков не просматривались |

## Сценарий и данные

- Только вымышленные поставщики, счета, заказы и сотрудники.
- Нет платежей, ERP, писем и других действий во внешних системах.
  Одобрение завершает учебное согласование.
- Сверяются два документа: счёт и заказ. Приёмки товара, налогов, скидок и
  конвертации валют нет. Поддерживаются USD, EUR и UZS с двумя знаками.

## Документы

- Принимается только UTF-8 текст и PDF с текстовым слоем. OCR нет.
- Лимиты: до 1 МиБ, 20 страниц и 200 000 символов.
- Поля извлекает простой парсер формата `Метка: значение`. Ручной
  исправки полей нет.
- Ограничение памяти PDF-процесса действует только на Linux; macOS его не
  принимает.

## Модель и помощник

- Настоящей LLM нет. Работают правило `demo-rules/1` и сценарные
  провайдеры для тестов, поэтому оценки ничего не говорят о живой модели.
- Объяснение помощника не хранится. Зависший вызов не прерывается, его поток
  просто перестают ждать.
- Квота помощника (20 запусков в час на процесс) читается без блокировки и
  при одновременных запросах может пропустить один лишний запуск.

## Доступ

- Токены без срока действия и ротации, SSO нет. Сотрудниками управляют
  только из командной строки.
- Ограничения частоты запросов к API нет, кроме квоты помощника.
- Документы не привязаны к подразделению. Запустивший процесс может его
  отклонить: «четыре глаза» относятся только к одобрению.

## Доставка событий

- Доставка как минимум один раз. Повтор безвреден только потому, что
  получатель учитывает ID события.
- Получатель — учебная заглушка на SQLite, только на loopback. Настоящих
  получателей нет.
- Строка доставки заблокирована во время отправки (до 5 с).
- `requeue` выполняет оператор из командной строки, без записи в аудит
  процесса.

## Интерфейс

- Токен вставляется вручную и живёт только в сессии вкладки.
- Подписи только на английском. В списке до 500 процессов, поиска нет.
- Страница проверена только во встроенном браузере приложения на macOS.

## Выпуск и эксплуатация

- Нет TLS, публикации образов, развёртывания, мониторинга, внешних журналов
  и менеджера секретов. Порты открыты только на `127.0.0.1`.
- Образы собраны и стек проверен только на macOS (Docker Desktop, arm64).
  Сборка для amd64 выполняется только в CI, который не подтверждён.
- Резервная копия логическая. Она не шифруется и не подписывается, по
  расписанию не делается. Восстановление идёт только в пустую базу той же
  ревизии.
- В копию входят таблицы PostgreSQL, но не SQLite получателя webhook.
  Его том сохраняется отдельно; атомарной копии двух хранилищ нет.
  Цикл восстановления CI сохраняет том получателя.
- Образ страницы большой (около 880 МБ) из-за зависимостей Streamlit.
- PDF-руководства собираются со шрифтами macOS. Сборка на Linux со шрифтом
  DejaVu не проверялась.
- Если проект лежит в папке, которую синхронизирует iCloud, окружение `.venv`
  повреждается. Держи проект вне таких папок.
